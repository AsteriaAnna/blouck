# 09 · Web BP 设计 Brief（交给网页设计师）

> 版本：2026-11-17  
> 目标：让一个**完全不了解项目**、但能力很强的网页设计师，在 1–2 小时内理解项目，并能独立做出一个面向 VC 的单页 BP 网站。  
> 本文件是唯一需要读的入口文档；不需要翻历史对话和内部设计文档。

---

## 0. 用 30 秒理解这个项目

**一句话：**  
blouck 把用户说的一句话，变成一个可以走进去、继续生长、还能玩的 3D 知识世界。

**它解决什么：**  
想学的人常常不是没内容，而是：知识连不起来、不知道下一步学什么、坚持不下去。

**它怎么解决：**  
- **知识线**：AI 把话变成概念节点和关系，形成个人知识图谱，并给出下一步探索方向；
- **游戏线**：把知识关系变成副本、闯关、成长机制，让学习像探索游戏。

**一个具体例子（请用这个理解产品）：**  
用户说：“RAG 从知识库检索资料，再用 Rerank 精排。”  
产品会生成：节点 `RAG / 知识库 / 检索 / Rerank`，关系 `RAG 使用 知识库`、`Rerank 属于 检索流程`，并给出下一步可探索方向。点节点能看到文档，点关系能看到这条关系为什么成立；点探索方向会出现下一个新节点。

**重要边界：**
- 这是一个**可运行原型/内测产品**，不是成熟商业产品；
- 游戏层（副本、闯关、经验值等）**正在开发**，网页上只能作为路线图/愿景，不要包装成已完成；
- 网页目标不是解释技术，而是让 VC 在 5 分钟内相信“这是新的学习方式，且团队能把它做出来”。

---

## 1. 这个网页的唯一任务

- **受众**：线上申请的 VC / 评审，大概率不会自己操作 demo。
- **目标**：让评审在 5 分钟内理解：
  1. 这是一个什么产品；
  2. 为什么现有方案不够；
  3. 为什么我们的“知识线 + 游戏线”不一样；
  4. 为什么现在能做、团队能做成；
  5. 下一步想做什么、需要什么。
- **成功标准**：
  - 5 秒内能说出“这是一个把输入变成知识世界、并用游戏让人坚持的学习产品”；
  - 60–90 秒内能读完核心叙事。

**不要做成**：产品说明书、技术文档、功能列表、内部设计稿展示。

## 2. 用户与故事

### 2.1 初始用户（按处境/心理/行为划分，不按“想学什么”划分）

**核心画像：处于职业转型或新领域上手期的知识密集型工作者**

- **年龄/阶段**：23–35 岁，一二线城市，知识密集型行业（互联网/AI/咨询/金融/设计/科研）或研究生；
- **触发场景**：转岗、转行、接手新项目、晋升、面试前，需要在 2–8 周内建立一个新领域的基本结构；
- **心理特征**：成长焦虑强；相信“体系化学习”能带来竞争力；对“学了连不起来、学了就忘”有痛感；愿意为效率和认知提升付费；喜欢尝鲜新工具；
- **行为特征**：每天大量输入（文章/课程/播客/文档），收藏多、整理少；用 Notion/Obsidian/ChatGPT/Anki 等工具；学习计划常中断；愿意在社区分享工具和方法；
- **付费习惯**：订阅生产力/学习工具、买课/知识付费；价格敏感度中等，但对“能解决结构问题”的工具愿意付费；
- **首轮验证**：招 10–20 位处于“转岗/新项目上手期”的种子用户，不按学科招，按“正在进入新领域”这个处境招；
- **第一个切入场景**：可以是 AI 产品/技术岗位（因为创始团队社区在这里），但**用户定义不是“AI 学习者”**，而是“正在进入新领域的知识工作者”。

**不是我们的初始用户**：按学科/考试标签划分的人（如“考研党/英语学习者”）；只是被动刷内容、没有输出/应用需求的人；需要固定课程打卡的人。

### 2.2 用户的三个困境

1. **学不完**：内容太多，完成率低。
2. **连不起来**：知识碎在聊天、笔记、收藏里，形成不了结构。
3. **坚持不了**：固定课程/打卡枯燥；没有方向，也没有乐趣。

### 2.3 我们的解法：两条线，一个循环

- **知识线（专业线）**：自动生成节点/关系 → 靠谱的个人知识图谱 → 给出探索方向。
- **游戏线**：随机副本、节点闯关、解锁新形态、经验值/奖励/排行榜/打卡。
- **协同**：知识线负责“靠谱 + 下一步”，游戏线负责“动机 + 坚持”；越学越有结构，越有结构越想学。

视觉上要让人一眼看出这是**一个产品**，不是两个产品。两条线用同一套世界视觉表达，不要拆成左右两个 SaaS 面板。

### 第 1 屏：Hero

**目的**：5 秒讲清“是什么 + 为什么不一样”。

- H1：**学习不是缺内容，是缺结构、方向和坚持。**
- 副标题：**blouck 用两条线解决：一条专业线，把你说的话变成靠谱的知识图谱；一条游戏线，让探索和闯关停不下来。**
- 主按钮：**查看产品界面**
- 次按钮：**预约交流**
- 信任条：**可运行原型 · 3D 知识世界 · 内测中**
- 视觉：
  - 背景使用动态节点-关系网络（SVG/Canvas 轻量动效），节点缓慢漂浮，鼠标靠近有轻微排斥/连线；
  - 前景叠加真实产品截图（优先 `docs/screenshots/web-bp/map.png`）；
  - 不要用 AI 机器人、紫蓝渐变、玻璃拟态。

### 第 2 屏：问题

**标题**：**为什么我们学了，却没学会？**

三张卡片：

1. **学不完**  
   MIT/Harvard 的 edX 研究：2017–18 年课程完成率只有 **3.13%**。  
   不是内容不够，是缺少让人走下去的结构。
2. **连不起来**  
   知识散在聊天、笔记、收藏里；知道很多点，但说不出它们怎么连。
3. **坚持不了**  
   固定课程 + 打卡：有路径，但不是你的知识；没有探索，也没有乐趣。

底部一句：**不是用户不想学，是现有工具只解决了“给内容”，没解决“学进去”。**

再加一句定位：
**我们不按“想学什么”分用户；我们服务的是“正在进入一个新领域、需要把碎片变成结构”的人。**

### 第 3 屏：现有方案，各解决一半

**标题**：**市面上的产品，各解决一半。**

四张对比卡（可横向滚动/网格）：

- **知识管理 / 知识图谱**（Obsidian、Notion、各类图谱）  
  存得住、自由；但节点要手动养，枯燥、门槛高，没有学习闭环。
- **学习 App**（Duolingo、题库、网课）  
  有路径、有练习；但课程固定，不是你的知识，探索空间小。
- **AI 问答 / 笔记**（ChatGPT、NotebookLM）  
  给答案、做总结；但一次性，不沉淀个人结构，不练，也不坚持。
- **企业知识图谱**（GraphRAG 等）  
  结构化很强；但重、工程化，不是个人学习体验。

**我们的位置**：  
**自动知识结构 × 主动探索 × 游戏化坚持**  
直接竞品暂时没有；相邻产品各解决一半。

> 视觉建议：这里放一个 2×2 矩阵。  
> 横轴：手动结构 ↔ 自动结构；纵轴：固定课程 ↔ 个人探索。  
> blouck 在右上角。

### 第 4 屏：两条线

**标题**：**两条线，一个学习循环。**

左侧：**知识线（专业线）**
- 一句话/语音 → 自动生成节点与关联；
- 节点/关系有文档、有来源、可编辑；
- 探索方向：下一步不是开盲盒，而是提前计划好的新节点。

右侧：**游戏线**
- 随机刷新副本、节点闯关；
- 闯关解锁新形态；
- 经验值、奖励、排行榜、打卡。

底部循环图：

```text
说/记 → 自动长图谱 → 探索方向 → 闯关/副本 → 解锁成长 → 继续探索
```

### 第 7 屏：早期验证 / 访谈

**这一屏不要写死标题、版式或固定文案。** 由设计师根据真实素材决定呈现方式；以下是素材原则，不是模板：

- **必须标注**：样本数量、访谈时间、样本来源（如“早期熟人访谈”）、是否匿名。

## 5. 视觉方向

### 5.1 气质

- 关键词：**纸感、知识世界、温暖、安静、有探索感**。
- 参考：Linear/Raycast 的信息层级 + Spline/Apple 的空间感；不要做成通用 SaaS。
- 颜色：
  - 背景：暖白/羊皮纸（#F7F1E5 附近）；
  - 文字：墨色（#2A2620）；
  - 强调：产品里的陶土色/青绿色（#C97B6B / #6E8C83）选一个为主。
- 字体：
  - 大标题可用宋体/衬线（思源宋体），正文用无衬线（思源黑体/系统字体）；
  - 中文优先，英文只做点缀。

### 5.2 动效

- Hero：节点缓慢漂浮、鼠标靠近轻微排斥、线缓慢生长；
- 滚动：模块淡入/上浮，关系线“生长”动画；
- 不要：全屏重型 WebGL、复杂粒子、滚动劫持、自动播放声音。

### 5.3 不要出现

- 紫蓝渐变、玻璃拟态、AI 机器人插画、股票风 K 线；
- 把“四类线/提示池/探索刷新”等内部概念画进网页；
- 未完成的答题/副本玩法截图冒充已完成。

## 7. 技术约束

- 单页静态网站：HTML + CSS + 少量 JS/SVG；不要后端。
- 响应式：桌面 + 手机（390px 宽不横向滚动）。
- 性能：首屏 LCP < 2.5s；图片压缩、懒加载；不使用视频。
- 可访问性：对比度、键盘可点、`prefers-reduced-motion` 关闭动画。
- 部署：GitHub Pages / Netlify / Vercel 任一；给出部署链接。
- 中文为主；代码/文件命名英文。
- 页面内容集中在一个 `content` 对象或清晰的分区，方便创始人改文案。

## 11. 术语表（设计师只需要这些）

- **节点**：一个概念卡片（如 RAG、Rerank、知识库）。
- **关系**：两个节点之间已确认的语义连接（如“RAG 使用 知识库”）。
- **探索方向**：AI 提前计划好的“下一个新节点”；点击后新节点出现。
- **副本**：由关系线生成的知识任务（流程排序/领域题），游戏层的一部分，开发中。
- **知识线**：自动生成和维护个人知识图谱的体验层。
- **游戏线**：让用户持续投入的探索/闯关/成长机制。
- **内测原型**：能演示核心链路，但不是生产级产品。
